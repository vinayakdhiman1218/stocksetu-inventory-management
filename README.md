# StockSetu

StockSetu is a capstone prototype for everyday inventory, billing and supplier workflows.

## Open the workspace

Open `index.html` in the VS Code browser preview. No package install or build step is needed.

The sign-in screen accepts any valid email and password to enter the local workspace. It does not create accounts or verify passwords.

## Included screens

- Public landing page with responsive layout, smooth scrolling and scroll reveal animations
- Working Features, How it works and Why StockSetu section links
- Overview with sales summary, stock alerts, activity and a seven-day chart
- Persistent dark mode toggle in the workspace header
- Product catalogue with search, stock filters, add/edit and CSV export
- Stock history for opening quantities, sales, purchases and adjustments
- Multi-product sales invoices, payment status and printable invoices
- Purchase receiving with supplier records and weighted average buy cost
- Sales returns that add returned quantity back to stock
- Customer and supplier directories, business settings, reports and CSV exports

## Prototype limits

Records are saved in this browser using `localStorage`. There is no connected server, real authentication, multi-user access or cloud backup yet. The included shop activity is fictional sample content for the capstone presentation.

## Files

- `index.html` — app entry page
- `styles.css` — layout, responsive styling and animations
- `app.js` — screens, interactions and browser-local records
